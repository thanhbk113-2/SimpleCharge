# Caveman Personal Cheat Sheet

## 1. Chế độ phản hồi

- `/caveman`: Trả lời ngắn gọn, bỏ lời chào/câu đệm, giữ 100% dữ kiện kỹ thuật, code, path.
- `/ultracave`: Nén tối đa bằng cụm từ ngắn (fragments), không lặp ý; vẫn giữ cảnh báo bảo mật nguy hiểm.
- `/megacave`: Chế độ mở rộng/nén cao (ghi chú thêm cách dùng thực tế của bạn).
- `/caveman off`: Quay lại văn phong đầy đủ, tự nhiên.

## 2. Git & Code Review

- `/caveman-commit`: Sinh commit message ngắn theo Conventional Commits (tiêu đề <= 50 ký tự, ưu tiên lý do "why", không dấu chấm cuối).
- `/caveman-review`: Review nhanh thay đổi code; mỗi ý 1 dòng theo mẫu `L<dòng>: <mức độ> <vấn đề>. <cách sửa>.` hoặc trả về `LGTM`.

## 3. Tối ưu & Tiện ích

- `/caveman-compress <đường_dẫn_file>`: Nén file văn bản sang dạng caveman để tiết kiệm token, có tự sao lưu file gốc.
- `/caveman-stats`: Xem thống kê sử dụng / tiết kiệm token.
- `/caveman-init`: Khởi tạo cấu hình/thiết lập ban đầu.

## 4. Danh sách Skill đã cài

- Chế độ & luồng: `caveman`, `ultracave`, `megacave`, `cavecrew`
- Quy trình code: `caveman-commit`, `caveman-review`, `caveman-compress`, `caveman-stats`, `caveman-init`
- Khám phá & chỉnh sửa: `caveman-explore`, `caveman-learn`, `caveman-manage`, `caveman-optimize`, `caveman-discover`, `investigate-first`, `lean-build`, `safe-refactor`, `surgical-patch`, `verify-and-stop`
